# Ambientes vacíos

Fotos de livings y comedores **vacíos** para la evaluación de punta a punta
(`amoblai eval e2e`) y para probar las webapps.

- Formatos: `.jpg`, `.png` o `.webp`. Nombres sin espacios (p. ej. `living_01.jpg`).
- Sacarlas horizontales, con buena luz y el piso visible.
- El pedido de cada ambiente va en `prompts.yaml` (si falta, se usa `default`).
- El repo es privado: las fotos se commitean para compartirlas en el equipo.
